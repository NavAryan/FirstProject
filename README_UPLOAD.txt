Mission Control 4.0

The application continues at the same GitHub Pages address and uses the original IndexedDB database.

For manual upload, replace the root application files together: index.html, styles.css, app.js, planner.js, state.js, defaults.js, ui.js, smart.js, db.js, sw.js and manifest.webmanifest. Keep the existing icon-192.png and icon-512.png.

Export a backup in More before changing devices or clearing browser data. Updating the app at the same URL does not intentionally reset stored progress. A pre-upgrade recovery copy is kept automatically.

Use Save & update when offered. Pause focus and close forms first. Do not clear Safari website data to force the update.

See README.md for usage, testing, privacy and limitations.
