MISSION CONTROL — INSTALL ON IPHONE

This package is a Progressive Web App (PWA).

IMPORTANT:
Apple only shows “Add to Home Screen” properly when the app is served from a normal HTTPS website.
Opening index.html directly from the Files app is not enough.

EASIEST INSTALL ROUTE
1. Put the contents of this folder on GitHub Pages, Netlify, Vercel, or another HTTPS host.
2. Open the HTTPS address in Safari on your iPhone.
3. Tap Share.
4. Tap “Add to Home Screen”.
5. Open Mission Control from the new Home Screen icon.

The app stores your tasks, XP, checklists, notes and money entries in your browser on that device.

FILES
- index.html — the app
- manifest.webmanifest — app installation metadata
- sw.js — offline caching
- icon-192.png / icon-512.png — Home Screen icons
